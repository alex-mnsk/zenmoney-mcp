# Необязательный локальный режим ZenMoney

Эта инструкция относится только к необязательному локальному Node.js-серверу. Основной облачный вариант по схеме FatSecret размещён, авторизован и проверен с реальными данными; его статус описан в [README.md](README.md).

## Возможности

| Инструмент | Назначение |
|---|---|
| `zenmoney_references` | Счета, балансы, категории, валюты и их идентификаторы |
| `zenmoney_transactions` | Доходы, расходы и переводы за период; страницы до 200 операций |
| `zenmoney_expense_report` | Расходы за период по валютам и категориям |
| `zenmoney_prepare_expense` | Черновик одного расхода с точным предварительным просмотром |
| `zenmoney_commit_expense` | Отправка одобренного черновика в ZenMoney |

Последние два инструмента появляются только при `ENABLE_WRITES=true`. Изменение и удаление существующих операций, счетов и бюджетов не реализованы. Это личный сервис с общим аккаунтом ZenMoney для всех выданных им подключений; не выдавайте доступ другим людям.

## Локальный запуск

Нужен Node.js 22.12 или новее. В PowerShell из папки проекта:

```powershell
npm ci
Copy-Item .env.example .env
```

Заполните `.env` локально в редакторе:

- `ZENMONEY_TOKEN`: действующий OAuth access token ZenMoney. Не отправляйте его в чат.
- `OWNER_PASSWORD`: случайный личный пароль минимум 32 символа. Он используется только на странице авторизации вашего сервера, не является паролем ZenMoney.
- `PUBLIC_URL`: внешний HTTPS-адрес сервера без пути, например `https://money.example.com`.
- `OAUTH_REDIRECT_URIS`: точный адрес возврата из настройки MCP-подключения ChatGPT. Несколько адресов разделяются запятой, без пробелов. Произвольные адреса клиентов запрещены.

Можно сгенерировать личный пароль локально:

```powershell
node -e "console.log(require('node:crypto').randomBytes(32).toString('base64url'))"
```

```powershell
npm test
npm start
```

По умолчанию сервер слушает только `127.0.0.1:8787`. Для локальной отладки допустим `PUBLIC_URL=http://localhost:8787`; ChatGPT не сможет использовать этот адрес напрямую. Секреты читаются из окружения/`.env`, а не из аргументов инструмента. OpenAI API key не требуется: проект предоставляет инструменты уже работающему ChatGPT и сам не вызывает модели.

## Откуда взять доступ ZenMoney

Официальный API использует OAuth 2.0. Для собственного OAuth-клиента зарегистрируйте реальный проект через форму в официальной документации, получите `consumer_key`, `consumer_secret` и согласуйте callback URL. Затем обменяйте пользовательский authorization code на токен через `https://api.zenmoney.ru/oauth2/token/`.

Документация также допускает получение личного токена через уже зарегистрированные сервисы. Это отдельное решение о доверии к такому сервису; проект не получает ваш пароль ZenMoney и не регистрирует приложение автоматически.

Этот выпуск принимает готовый access token; встроенного обновления токена ZenMoney нет. При его истечении замените `ZENMONEY_TOKEN` локально и перезапустите сервер. OAuth-токены подключения ChatGPT — отдельные токены; их обновление реализовано.

## Подключение ChatGPT

1. Подготовьте личный HTTPS-хост или поддерживаемый защищённый MCP-туннель. Для обычного HTTPS reverse proxy передайте запросы на `127.0.0.1:8787`, сохраняя пути. Нужны `/mcp`, `/authorize`, `/token`, `/register`, `/revoke`, `/owner/approve` и `/.well-known/*`.
2. В ChatGPT откройте добавление собственного MCP-сервера/плагина. Доступность зависит от вашего аккаунта и настроек рабочего пространства.
3. Укажите `https://ВАШ-ХОСТ/mcp`, OAuth и динамическую регистрацию публичного клиента (`token_endpoint_auth_method=none`). Скопируйте показанный ChatGPT callback URI в `OAUTH_REDIRECT_URIS`, затем перезапустите сервер.
4. Выполните подключение: откроется ваша страница разрешения доступа. Проверьте адрес сервера и возврата, введите личный `OWNER_PASSWORD`.
5. Начните с запроса: «Покажи мои счета и валюты в ZenMoney», затем «Проанализируй расходы за октябрь 2026 по категориям, отдельно по валютам».
6. Для записи измените `ENABLE_WRITES=true`, перезапустите сервер и обновите список инструментов в ChatGPT. Пример: «Подготовь расход 15 BYN за 28 октября 2026 со счёта … в категории …». После точного предварительного просмотра отдельно подтвердите расход.

Официальная документация OpenAI описывает MCP и OAuth 2.1 с PKCE и динамической регистрацией. Эта реализация использует SDK MCP, discovery, PKCE S256, одноразовые коды, ограниченные по времени access/refresh tokens и ротацию refresh tokens. Она не передаёт ChatGPT токен ZenMoney. Совместимость с вашим аккаунтом ChatGPT необходимо проверить после размещения; локальный тест использует официальный MCP-клиент, а не реальную сессию ChatGPT.

### Размещение через Docker

В проект включён Dockerfile. После заполнения `.env`:

```powershell
docker build -t personal-zenmoney .
docker volume create personal-zenmoney-data
docker run -d --name personal-zenmoney --restart unless-stopped --env-file .env -e HOST=0.0.0.0 -p 127.0.0.1:8787:8787 -v personal-zenmoney-data:/app/.data personal-zenmoney
```

Перед этим портом нужен HTTPS reverse proxy или поддерживаемый туннель; публичный HTTP-порт с финансовыми данными открывать не следует. Внешнее размещение этим проектом не выполнено. Ресурсы сервера, домен и TLS выбирает владелец. Для локального stdio MCP-клиента есть `npm run stdio`; в ChatGPT используется HTTP-вариант.

## Правила расчёта

- Границы периода включены; используются календарные даты операций ZenMoney. Для «сегодня» используйте часовой пояс владельца, в данном случае Europe/Minsk.
- Удалённые операции исключены. Операции `hold` по умолчанию исключены; их можно включить явно.
- Расход — операция с `outcome > 0` и `income = 0` на счёте `inBalance=true`. Переводы и долговые операции с двумя ненулевыми сторонами исключаются. Это определение может отличаться от отчётов интерфейса ZenMoney.
- Валюта расхода — `outcomeInstrument`, то есть валюта списания со счёта. Суммы в разных валютах не складываются и не пересчитываются по сегодняшнему курсу.
- Расчёты выполнены Decimal; неизвестные остатки возвращаются как `null`. Курс на дату операции не выдумывается.
- При нескольких категориях операция входит в одну группу с набором этих категорий, чтобы сумма не считалась несколько раз.
- Каждый запрос чтения получает полный снимок Diff с `serverTimestamp=0`. Данные не сохраняются в локальный финансовый кэш; у большого аккаунта чтение может быть медленным. В результатах есть время получения и метка сервера. Параллельные чтения делят один текущий запрос.
- Выгрузка операций постраничная; для полного анализа списка нужно читать до `next_offset=null`. Отчёт рассчитывается по всему снимку, независимо от страниц.

## Запись и хранение

Черновик живёт 10 минут в памяти. Запись требует `confirmed=true` и явного согласия владельца в чате; проверка человеческого согласия остаётся обязанностью ChatGPT/клиента. Сам сервер не может отличить введённый моделью флаг от человеческого подтверждения. Инструмент записи помечен как изменяющий внешние данные.

Перед отправкой сервер сохраняет UUID попытки в `.data/writes.json`. Повтор того же черновика, в том числе после перезапуска, не отправляет операцию снова. При обрыве связи результат остаётся `unknown`: проверьте операцию по UUID в ZenMoney, прежде чем создавать новый черновик. Автоматических повторов записи нет. Поддерживается один процесс сервера на журнал; несколько реплик с общим журналом не поддерживаются. Журнал должен быть постоянным и доступным для записи. Не удаляйте его при неопределённом результате.

В журнале находятся UUID, статус и время попытки, без суммы и текста операции. Полный финансовый снимок и черновики находятся в памяти процесса. OAuth-клиенты, коды и токены ChatGPT также в памяти: после перезапуска потребуется повторное подключение ChatGPT. Для отзыва всех подключений перезапустите сервер; при компрометации смените личный пароль. Защитите `.env`, процесс и диск средствами своей ОС. Сервер не журналирует тела финансовых запросов и секреты.

## Проверено

`npm test`: семь тестов с искусственными данными — точность сумм, разделение валют, исключение переводов/удалений/hold, группировка нескольких категорий, пустой аккаунт и явные удаления Diff, страницы, блокировка записи, предварительный просмотр, журнал повторов и неопределённого результата, OAuth/PKCE, отказ постороннему callback, одноразовые коды, ротация refresh token, аутентифицированный HTTP-вызов инструмента официальным MCP-клиентом, отклонение чужого Origin и неправильной даты. Отдельно проверены запуск через stdio и атрибуты инструмента записи.

Облачное подключение и чтение реального ZenMoney проверены и описаны в README. Реальные операции записи не выполнялись. Этот необязательный локальный сервер не размещался.
